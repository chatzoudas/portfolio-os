A retro Windows-style desktop OS that serves as my interactive portfolio. Drag windows, open apps, and play fully working mini-games.

**Live Demo:** https://chatzoudas.dev — embedded in my main portfolio site · **Main Portfolio:** https://chatzoudas.dev

## Run locally

```bash
npm install
npm run dev
```

```bash
npm run build   # production build
npm run preview # preview the build
```
